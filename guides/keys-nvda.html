NVDA keys: every key

This page is made from TurnOver's own command tables (`turnover-coretest --keys-reference`, 20 Oct 2026), so it matches the build it came with. Don't edit it by hand.

The NVDA keys style (the Windows style): NVDA's own keys, doing what they do in NVDA. TurnOver in a key means the NVDA key: Caps Lock, or Control and Option together. NVDA's Alt is the Mac's Command key, by position. Keyboard help (the TurnOver menu, Keys) says what any key does without doing it; Command Control Comma, then Slash, lists the keys that work where you are.

Switch styles with Command Control Comma, then K. TurnOver's own commands behind Command Control Comma are the same in every style: see The TurnOver layer.

Windows keys

KeyWhat it does
F10Opens the application's menus; closes them if open (Windows: Alt or F10). Also Command on its own
Command F4Quits the application (Windows: Alt+F4)
Control F4Closes the window or tab (Windows: Control+F4)
Option BStatus menus; lists the status menus at the right of the menu bar, TurnOver's own item last (Windows: Windows+B)
Option TabApplication chooser; lists every application with a window, system alerts too, to switch to (Windows: Windows+Tab, Task View)
Shift F10Opens the context menu, as Control+Return does (Windows: the Applications key, Shift+F10). Also right Option on its own
Control Shift EscapeForce quit, as Task Manager's key (Windows: Control+Shift+Escape)

In the apps

Keys an app's own support adds at the app level, in that app only; the keys above work there too. Keys that belong to a document inside an app (Word's headings, comments and tables, a web page's quick keys) are in The apps and Reading and say all.
