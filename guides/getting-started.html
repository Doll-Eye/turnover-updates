Getting started

TurnOver is a screen reader for the Mac. It uses VoiceOver's keys, so what you already know works, and it reads the apps you use every day more simply than VoiceOver does. It runs on macOS 14 or later, on Apple silicon and Intel.

Installing

  1. Move TurnOver to your Applications folder and open it. A welcome message explains what it needs.
  2. Turn TurnOver on in System Settings, Privacy and Security, under Accessibility (called Device Control and Data Access on macOS 27) and under Input Monitoring. macOS asks for the first; if it doesn't ask for the second, TurnOver tells you where it is.

Starting and stopping

When TurnOver stops, VoiceOver takes over.

Updates

TurnOver checks once a day. When there is a new build it says so and asks whether to install it. The TurnOver menu, About and updates, Updates checks now; What's new lists every build's changes.
