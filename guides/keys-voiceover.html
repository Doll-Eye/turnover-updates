VoiceOver keys: every key

This page is made from TurnOver's own command tables (`turnover-coretest --keys-reference`, 29 Oct 2026), so it matches the build it came with. Don't edit it by hand.

The VoiceOver keys style (the Mac style): VoiceOver's own keys, doing what they do in VoiceOver. TurnOver in a key means the TurnOver key: Control and Option together (VO), or Caps Lock. Keys VoiceOver has that aren't listed here go to VoiceOver as usual where VoiceOver reads, and do nothing special where TurnOver reads. Keyboard help (the TurnOver menu, Keys) says what any key does without doing it; Command Control Comma, then Slash, lists the keys that work where you are.

Switch styles with Command Control Comma, then K. TurnOver's own commands behind Command Control Comma are the same in every style: see The TurnOver layer.

In the apps

Keys an app's own support adds at the app level, in that app only; the keys above work there too. Some commands apply only in the relevant control or window. Keys that belong to a document inside an app (Word's headings, comments and tables, a web page's quick keys) are in The apps and Reading and say all.
