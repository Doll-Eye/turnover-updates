JAWS keys: every key

This page is made from TurnOver's own command tables (`turnover-coretest --keys-reference`, 20 Oct 2026), so it matches the build it came with. Don't edit it by hand.

The JAWS keys style: JAWS's laptop layout. TurnOver in a key means the JAWS key: Caps Lock, or Control and Option together. Only the keys that differ from NVDA's are JAWS's own; every other key is NVDA's, so the NVDA keys page lists the rest. Keyboard help (the TurnOver menu, Keys) says what any key does without doing it; Command Control Comma, then Slash, lists the keys that work where you are.

Switch styles with Command Control Comma, then K. TurnOver's own commands behind Command Control Comma are the same in every style: see The TurnOver layer.

During say all

These keys apply only while say all is reading.

KeyWhat it does
Left arrowDuring say all: back a sentence, and carries on reading (JAWS: Left Arrow)
Page downDuring say all: slower, for this say all only (JAWS: Page Down)
Page upDuring say all: faster, for this say all only (JAWS: Page Up)
Right arrowDuring say all: on a sentence, and carries on reading (JAWS: Right Arrow)

In the apps

Keys an app's own support adds at the app level, in that app only; the keys above work there too. Keys that belong to a document inside an app (Word's headings, comments and tables, a web page's quick keys) are in The apps and Reading and say all.
